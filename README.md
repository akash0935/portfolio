# Akash Rathore — VLSI & Digital IC Design Portfolio

An interactive, high-performance 3D engineering portfolio for **Akash Rathore**, an Electronics & Communication Engineering (ECE) undergraduate specializing in **VLSI Fundamentals, Digital Logic Design, RTL Architecture (Verilog HDL), and Hardware Systems**.

---

## ⚡ Tech Stack & Architecture

- **Frontend Core**: Vanilla JavaScript (ES6+), HTML5, CSS3 (Custom Glassmorphic System)
- **3D & Motion**: GSAP, Three.js, Hardware-accelerated canvas frame rendering
- **Build Tool**: [Vite](https://vitejs.dev/) with Multi-Page Rollup architecture
- **Hosting**: GitHub Pages / Vercel / Netlify

---

## 💻 Local Development

Clone the repository and install dependencies:

```bash
# Clone repository
git clone https://github.com/akash0935/portfolio.git

# Navigate to project folder
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

---

## 📦 Production Build

To compile production-optimized assets:

```bash
npm run build
```

The compiled output will be generated inside the `dist/` directory, ready to deploy to any static hosting provider.
