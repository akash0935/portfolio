Voice-Controlled Home Automation System

Designed and implemented an offline voice-controlled smart home automation system using an Arduino Uno (ATmega328P-PU), an offline speech recognition module, Mini DF Player audio feedback, and a 4-channel optocoupled relay module to switch AC appliances and DC loads without internet dependency. Both the formal engineering report and defense presentation are available below.

⚡ Technical Specifications & Overview

  • Project Domain Embedded Systems · Offline Voice Processing · Power Electronics
  • Team & Guidance Akash Rathore & Darshan Sharma · Guided by Mr. Prema Ram & Mr. Ajay Kumar Kushwaha
  • Main Controller Arduino Uno (ATmega328P-PU Microcontroller)
  • Voice Input Interface Offline Speech Recognition Module with Electret Mic (Trained Commands)
  • Audio Feedback Unit Mini DF Player + Micro SD Card (MP3 Voice Confirmation Alerts)
  • Power Switching Unit 4-Channel Optoisolated Relay Module (250V AC / 10A rating)
  • Controlled Output Loads High-Voltage AC Appliances, DC Fan, Indicator LED / Bulb
  • System Flow Spoken command ("Light On", "Fan Off") → Voice module compares acoustic pattern → Sends trigger signal to Arduino Uno → Controller toggles Relay state & triggers DF Player audio confirmation.
  • Key Innovation & Cost 100% offline execution without cloud dependency or latency. Total hardware expenditure: Rs. 830.
