Voice-Controlled Home Automation System

Designed and implemented an offline voice-controlled smart home automation system for switching high-voltage AC appliances using speech recognition, embedded logic, and optocoupler relay isolation without requiring an internet connection. Both the formal engineering report and defense presentation are available below.

⚡ Technical Specifications & Overview

  • Project Domain Embedded Systems · Voice Command Processing · Power Electronics
  • Main Controller Microcontroller Board (ESP32 / Embedded Processing)
  • Voice Input Interface Offline Speech Recognition Module with Electret Microphone
  • Power Switching Unit 4-Channel Optoisolated Relay Module (250V AC / 10A rating)
  • System Flow Voice Command spoken → Recognition Module decodes acoustic pattern → Sends UART command byte to Controller → Controller toggles corresponding GPIO → Relay switches appliance ON/OFF.
  • Key Innovation 100% offline execution without cloud dependency, eliminating privacy concerns, internet latency, and connectivity dropouts.
