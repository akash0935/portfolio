Laser Thief Detection System

Built an optical perimeter security intrusion system using a concentrated 650nm laser-LDR beam, threshold-based voltage divider detection logic, and an ESP32 microcontroller with active buzzer alarm and IoT alert capability. Full project report and seminar presentation are available below.

⚡ Technical Specifications & Overview

  • Project Domain Optical Perimeter Intrusion Detection · Embedded Control · IoT
  • Team & Guidance Akash Rathore & Kuldeep Patel · Guided by Mr. Manish Purohit (Lecturer)
  • Main Controller ESP32 Microcontroller (ADC Threshold Sensing & Wi-Fi Alert Ready)
  • Optical Transmitter 650nm Red Dot Laser Diode Module
  • Photo-Receiver Cadmium Sulfide (CdS) LDR with 10kΩ Voltage Divider Resistor
  • Alert Output 5V High-Decibel Active Buzzer & Indicator LED
  • Detection Principle Uninterrupted laser keeps LDR resistance minimal. Intruder crossing triggers instant resistance surge, shifting divider voltage beyond the programmed trigger threshold to sound alarm.
  • System Features & Cost Low-cost, reliable perimeter defense with Wi-Fi IoT capability. Total hardware expenditure: Rs. 670.
